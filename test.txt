# 1. Plain Text

**Plain text** is text without any styling or formatting attached to it. It contains only simple characters and does not include things like fonts, colors, images, or other formatting.

Plain-text files are commonly saved with the **`.txt`** extension.

### Advantages of Plain Text

#### 1. Same Output on Different Systems

Plain text can generally be opened on different computers and operating systems without requiring a specific application or software.

For example, if you write:

```text
Hello Node.js
Welcome to Backend Development
```

the basic text remains the same when opened on different systems.

Unlike rich-text documents, plain text does not depend on formatting, fonts, or special software.

#### 2. Fast and Flexible

Plain-text files are simple because they contain only text and do not store additional formatting information.

As a result, they are:

* Easy to create
* Easy to edit
* Fast to open
* Easy to transfer
* Flexible to use

#### 3. Small File Size

Plain-text files generally have a **small file size** because they don't contain additional formatting information such as:

* Fonts
* Colors
* Images
* Layout information
* Text styles

### Example

A simple `.txt` file:

```text
Hello Node.js
Welcome to Backend Development
This is my first backend application.
```

This file contains only text, making it lightweight and easy to read.

### Plain Text vs Rich Text

| Plain Text             | Rich Text                       |
| ---------------------- | ------------------------------- |
| No formatting          | Supports formatting             |
| Simple text only       | Fonts, colors, styles, etc.     |
| Usually smaller        | Usually larger                  |
| Easy to open anywhere  | May require compatible software |
| Simple and lightweight | More visually expre             |
